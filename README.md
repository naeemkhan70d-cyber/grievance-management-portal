# Grievance Management Portal

A full-stack role-based grievance management system that enables citizens to submit grievances and officers to manage, track, and resolve complaints efficiently.

## Features

### Citizen
- Register & Login
- Submit Grievances
- Track Complaint Status
- View Complaint History
- Update Profile

### Officer
- Secure Login
- View Assigned Complaints
- Update Complaint Status
- Resolve Grievances
- Dashboard & Analytics

## Tech Stack

### Frontend
- React.js
- TypeScript
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- JWT Authentication
- Role-Based Access Control (RBAC)

### Database
- MongoDB
- Mongoose

## Project Architecture
